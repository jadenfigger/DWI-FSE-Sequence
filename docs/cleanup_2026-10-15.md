Archive metadata includes a per-file SHA-256 manifest, the original file inventory, protected-file hashes, and the pre-cleanup Git status. The archive is **local and ignored by Git**; retain it when copying or backing up this project.

## Restore historical outputs

Run from the project root:

```text
python tools/restore_cleanup_archive.py --list
python tools/restore_cleanup_archive.py --prefix runs/magnetization_components/
python tools/restore_cleanup_archive.py --prefix runs/echo_snapshot_comparison/
python tools/restore_cleanup_archive.py --prefix dist/
```

Omit `--prefix` to restore everything. Prefixes can be repeated. Restoration verifies selected archive hashes and refuses to overwrite differing existing files; identical existing files are skipped.
