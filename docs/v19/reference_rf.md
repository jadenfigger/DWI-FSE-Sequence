## Axis derivation and ideal signal cost

Figure1 labels preparation90y,180x,tip-90y,re-excitation90y and imaging refocusx. Applying a common RF-axis offset of270 degrees gives the v18-compatible axes0,270,180,0,270 degrees. The repository Bloch engine uses left-handed rotation: phase0 maps Mz to+My; phase180 maps+My to+Mz. Thus v191's storage/re-excitation pair is distinct from v192's elimination pulse at270 degrees, which retains My and moves Mx to-Mz. Each axis must also include the existing `phase_90` cycling offset. This is a mathematical coordinate transformation; physical transmitter phase polarity must be calibrated against the target console before scanner validation.

An ideal quarter-turn about the retained MG axis preserves that component, while storing its quadrature. This independently derives the Alsop elimination axis. At each voxel, added spatial phase phi gives the retained component proportional to cos(phi+theta), containing two conjugate spatial harmonics. Recalling only one harmonic gives one-half the ideal original coherent signal, not full signal. ss-MGOT stores the same selected component, spoils the other, and re-excites; it also has the half-signal cost before relaxation and finite-profile losses. This derivation does not assert that finite scanner pulses achieve ideal transfer.

For a +D initial physical dephaser in the model with Mxy rotating exp(-i2piDz), the stored/retained sinusoid contains +/-D harmonics. A refocus conjugates transverse harmonics. Selecting a harmonic with a post-RF +D recall and restoring with -D returns the dephased state before the next refocus; matched ordinary crushers preserve that desired evolution. Fig1 adds D to the right crusher and subtracts D from the left. Which signed component is selected must be checked with the actual leading/trailing crushers and non-180 RF, including unwanted harmonic collisions. After an intervening crusher C, even a pure retained component acquires exp(-i2piCz); its resulting Mx is known phase evolution, not automatically failed elimination.

Original Alsop p529-530 additionally specifies that the elimination pulse shares the refocus phase and sits half an echo spacing before the first refocus, at the preparation echo center. Its reported first-five angles are142.2,94.9,69.2,63.0,60.2 degrees, with later angles close to60; first two clinical echoes were discarded. An eight-entry completion using60,60,60 must be labeled an approximation. Original dephasing used the phase axis, separating it from crushers; using the slice axis requires checking harmonic coincidences. The ideal signal halves. These are original-Alsop facts, not an exact table for Gibbons' comparator. [Alsop primary source](https://onlinelibrary.wiley.com/doi/pdf/10.1002/mrm.1910380404).

## RF library interface and new inputs

The uploaded `scanner/utilities` now contains actual `rfstd44.seq`, `g3040_15.seq` and all other v18 library/include dependencies, including `tstex_15.pph`. Earlier missing-library statements have therefore been superseded. `m3031_15.pph` defines the real interfaces: `NEWSHAPE_MAC` records frame address, waits, board, nominal duration and bandwidth; `NEWSHAPE_SETUP` sets board multipliers and addresses; `MR3031_RFSTART` includes RF preparation/warmup. No fictitious pulse loader has been introduced.

EVO manual p132 identifies `.seq` as binary WavEd waveform-editor files, with `#use RF1 "path" alias`; p142 documents RF macros. The actual header and embedded generators support independent decoding, but a hand-built binary asset still requires round-trip validation against supplied files and vendor compiler/WavEd readback. Duration and bandwidth in `NEWSHAPE_MAC` do not alter missing sample coefficients. RF calibration must use pulse-specific area and transfer, amplifier voltage gain, phase encoding and verified real magnitude/polarity controls; scaling/clipping old90/180 multipliers is not acceptable proof.

## Completion boundaries

No exact Gibbons pulse coefficients or full flip schedules were supplied in the references. Newly designed or vendor-sinc scanner adaptations can implement the mechanisms, but their finite transfer and phase errors must be measured and their benchmark status must remain approximate. Independent physical/event validation uses actual decoded scanner waveforms; standalone MATLAB/Python designs are supporting RF experiments only. Compiler, console phase/gradient calibration, RF amplitude calibration and scanner verification remain separate qualification stages.
