# Superseded source inputs for the crusher scan

These text files are byte-identical copies of the reviewed v3 PPL inputs before
the crusher-window restriction. They are retained solely to reproduce the
exploratory 2-D scan in `examples/v19_crusher_scan.py`, including values that the
final scanner sources reject. They are not installation artifacts.

Use only the final PPL/PPR pair under `scanner/` when assessing the implemented
restrictions. No file in this project has been compiled or verified on a scanner.
