Reading the views

  • Frame. Everything is in the frame rotating at the RF carrier. A 90° pulse with phase 0° tips +z to +y′; phase 270° (−y′) is the CPMG refocusing axis of these files. Free precession turns Mxy clockwise seen from +z.
  • Ensemble. The voxel is split into slices of z (through-slice position). Each z holds several isochromats spread over the in-plane voxel (x, y), a Lorentzian off-resonance spread (T2′), the B1 spread, and the motion phase. The default 3D view averages each z-slice over those isochromats, so a crusher looks like a fan of vectors twisting along z.
  • Signal. The bottom row of the diagram is |mean Mxy| over the whole ensemble, divided by the number of spins inside the nominal slice. 1.0 is the full slice magnetization; the slice-profile wings can add or remove a little.
  • Dephasing states. Fn is the transverse magnetization that has been wound by n turns across the slice (EPG “F states”), Zn the longitudinal pattern stored with n turns. A crusher moves Fn → Fn+k; a refocusing pulse swaps Fn ↔ F−n and parks some of it in Zn. Only F0 is signal.
  • Model limits. Spins are static. Motion during the diffusion lobes is represented by a phase added at one instant (after the second lobe by default). A coherent φ is the shot-to-shot bulk-motion phase that Alsop and ss-MGOT are built to tolerate; a phase spread across isochromats is intravoxel dispersion (diffusion attenuation), which no sequence recovers. Water only, no fat. Finite RF uses the file's shapes, step-integrated; “ideal” replaces each pulse by an instant rotation with a rectangular slab.

Keys and files

  • Space play/pause · ← → step 0.05 ms (Shift 1 ms) · [ ] previous/next event
  • Load any Pulseq 1.3–1.5 .seq. Long protocols: set the simulation window in Ensemble & window; each window starts from equilibrium.
  • Built-in DW-FSE files come from examples/compare_prepared_fse.py (TE 64 ms, ESP 16 ms, ETL 8, b 1000 s/mm² on read, excitation phase 0°). The hard-pulse examples are examples/ex*.seq.
  • The simulator reproduces dwfse/simulate.py echo amplitudes to about 0.003 of M0 on these files.
